*Personal Book Tracker*

As a self proclaimed book lover, I keep coming back to this idea of a book tracker to tinker with. 
This time I'm focusing on the following stack:
- Typescript
- Express
- PostgreSQL
- React

I'm also learning how to do basic deployment with AWS and how to set up some basic test cases.

*Goals*

The goal of this app is to keep my collection of read books and keep my To Be Read list up to date. Each book will be stored in a card with extra details such as my personal rating and review/notes. 

*Requirements*

Basic requirements for this are as follows:
- Ability to add a new book with name, author, genre, if it's read, rating, and review/notes
- Ability to see all of the books in a grid
- Ability to click into any book card to see or edit information
- Ability to search for any book by title. More advanced search is not being considered for MVP
- Ability to quick filter books by genre in a sidebar to the main book grid
